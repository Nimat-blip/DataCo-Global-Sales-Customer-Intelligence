# DataCo-Global-Sales-Customer-Intelligence
An interactive two-page Power BI dashboard analyzing sales performance, profitability, customer segments, regional trends and delivery risks.
Sales & Customer Intelligence Dashboard – DataCo Global

Project Overview

This project involved developing a two-page interactive Power BI dashboard for DataCo Global, a multinational B2C company.

The objective was to transform raw sales data into meaningful business insights that support decision-making around sales performance, profitability, customer segmentation, regional performance and delivery operations.

Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modelling
- Microsoft Excel

Data Preparation & Modelling

- Cleaned and transformed raw sales data using Power Query.
- Designed a Star Schema data model.
- Created FactSales and dimension tables.
- Built a custom Date Table using DAX/Power Query.
- Established relationships between fact and dimension tables.

Dashboard Pages

1. Executive Summary

Provides an overview of business performance through:

- Total Sales
- Total Profit
- Total Quantity Sold
- Average Delivery Time
- Year-over-Year (YoY) performance
- Sales by Region
- Top Performing Products
- Customer Segment Performance

2. Deep Dive Analysis

Provides detailed insights into:

- Sales trends over time
- Profit breakdown by category and department
- Late delivery risk
- Sales performance by customer segment and region

Key Business Insights

This analysis highlighted important findings, including:

- Western Europe recorded the highest sales performance.
- South Asia recorded the lowest sales performance.
- The Consumer segment accounted for 51.9% of customers.
- First Class shipping recorded the highest late delivery risk.
- Standard Class recorded the highest number of late-delivered orders.

Key Performance Indicators

- Total Sales: $36.78M
- Total Profit: $3.97M
- Total Quantity Sold: 384K
- Average Delivery Time: 3.5

Project Objective

To demonstrate practical data analytics skills by transforming business data into actionable insights through data preparation, modelling, DAX calculations and interactive visualisation.
